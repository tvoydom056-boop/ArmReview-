# Импорт борцов и матчей EVW 24–26

**Статус:** реализовано и выполнено (2026-10-06) на облачной базе Turso (общая для dev и прода на Vercel) с фото в Vercel Blob:
122 борца, 6 турниров, 47 матчей, дублей 0 (`EVW_CHECK=1`); на проде данные видны. На сервер Danil (`deploy/DEPLOY.md`) не запускалось.
**Источник данных:** `data/evw/` — `athletes.json` (81 борец из рейтинга EVW, 78 фото), `events.json`
(45 матчей EVW 24–26, из них один отменён — не импортируется), `extra.json` (русские имена, ручные страны,
алиасы имён, русские названия мест). Результаты собраны с evwsports.com, armrankings.com, goldsarm.com;
расхождения источников — в `notes` внутри `events.json`.
**Ссылки:** [PROJECT.md § 11–12](../../../PROJECT.md), [deploy/DEPLOY.md](../../deploy/DEPLOY.md), образец — `scripts/seed.ts`.

Проверка: **T** — автотест Vitest, **M** — ручная, **—** — не проверяется.

## Как запускать

```powershell
npm run import:evw                       # борцы, турниры, матчи — без фото
$env:EVW_PHOTOS = "1"; npm run import:evw  # то же + фото
$env:EVW_DRY_RUN = "1"; npm run import:evw # только план, в базу не пишет
```

Флаги — переменными окружения: `payload run` не пробрасывает аргументы командной строки.
Скрипт идемпотентный: борец и турнир ищутся по `slug`, матч — по (турнир, борец 1, борец 2, рука).
Фото догружается только борцу, у которого его ещё нет.

**На сервере:** сначала `deploy/backup.sh`, затем скрипт запускает Danil (DATABASE_URI и MEDIA_DIR — как у
сервиса). Демо-данные (`npm run seed`) на боевой сервер по-прежнему не запускать.

## Устройство

`lib/evwImport.ts` — чистая функция `buildImportPlan` (данные → список записей), `scripts/import-evw.ts` — только
запись через Local API. Админку, схему и миграции не трогали.

| Было (JSON) | Стало (коллекция.поле) | Правило |

## Решения Danil

- **Порядок борцов.** У старых матчей порядок не важен: победитель стоит первым. Для **новых** турниров порядок брать
  из карты турнира, иначе он выдаёт исход (PROJECT.md § 12). Скрипт — только для этой однократной загрузки.
- **Категории — как у EVW.** `lib/weightClass.ts` переведён на границы 70 / 77 / 85 / 95 / 105 / 115:
  Полулёгкий, Лёгкий, Полусредний, Средний, Полутяжёлый, Тяжёлый, выше 115 — Супертяжёлый.
  `TODO(вопрос 48)`: русские названия подтвердить у Влада.
- **Фото** — флаг `EVW_PHOTOS=1`; на боевой сервер заливать только с разрешения EVW (PROJECT.md § 11).
- **Имена латиницей** (2026-10-06, вместо кириллицы): таблица `namesRu` удалена. Подсказка в админке «Кириллицей…» у поля `name` устарела — коллекцию не трогали. Уже созданных борцов переименовывает `EVW_SYNC_NAMES=1`.

  «За год» — по дате турнира (`lib/topFilter.ts`, T `topFilter.test.ts` (4)). Пьедестал топ-3 пропущен: в макете блок

  Цвет не единственный носитель: рядом текст. M: «Иван Тестов» — «аутсайд», 375 px без скролла. Легенда — без описаний
  стилей: в макете они помечены «нет данных».

## Кнопка темы (доп. задача)
- `ThemeToggle` (клиентский, без состояния React — иконку выбирает CSS через токены `--icon-moon/--icon-sun`),
  выбор хранится в `localStorage['theme']`, без выбора — системная тема. Тёмные токены продублированы под
  `:root:not([data-theme='light'])` в media и `:root[data-theme='dark']` — держать в синхроне.
- **Скрипт темы без мигания.** Три варианта проверены замером «какое data-theme стоит к первому кадру»:
  `<script>` в `<head>` — работает, но React 19 пишет в консоль «Encountered a script tag…»;
  `next/script beforeInteractive` — предупреждения нет, но тема выставляется через 20–70 мс ПОСЛЕ первого кадра
  (в App Router скрипт кладётся в очередь `__next_s` в `<body>`) → мигание;
  **выбрано:** `<div hidden dangerouslySetInnerHTML="<script>…</script>">` первым в `<body>` — браузер исполняет
  при парсинге до отрисовки, React script-элемента не создаёт. Замер: на первом кадре уже `light`.
- **Cookie для темы не используем:** политика/баннер обещают «один cookie» (голос). Серверный вариант через cookie
  убрал бы мигание без скрипта, но потребует правки текста политики — решение Danil'а.
- **Аудит консоли** (Edge/CDP: все страницы × 2 темы + модалка + 404, клики по «Показать» и кнопке темы):
  ошибок и hydration-предупреждений нет. Единственное — dev-предупреждение Next про LCP-картинку на `/athletes`
  (`AthletePhoto`, до рестайла тоже было): лечится `priority`/`loading="eager"` у первых фото — не трогал.

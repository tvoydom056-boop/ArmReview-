# Порядок борцов на карте не должен выдавать победителя

Найдено при ревью 2026-10-18: в импортированных турнирах EVW 24–26 победитель стоит первым в 44 матчах из 44
(проверено по `/api/matches`). Это ломает обещание PROJECT.md § 12: счёт спрятан, а исход виден по порядку имён.

## Что сделано (в коде; в базу не применялось)

| Сценарий | Как |
|---|---|
| WHEN импорт собирает матч THEN стороны меняются местами примерно в половине матчей, детерминированно | `shouldSwapSides` в `src/lib/evwImport.ts` (ключ: турнир + оба слага + рука); вместе со сторонами переезжает счёт |
| WHEN импорт запускают повторно THEN дублей нет в любом порядке сторон | поиск пары в `scripts/import-evw.ts` идёт в обоих порядках |
| WHEN нужно поправить уже загруженное THEN `npm run fix:evw-order` | `scripts/fix-evw-order.ts`: меняет athlete1/2, score1/2, technique1/2; победителя не трогает; без `EVW_APPLY=1` только показывает |

Проверка: `evwImport.test.ts` (доля «победитель первым» между 30 и 70 %, счёт идёт за своей стороной);
сухой прогон `fix:evw-order` на локальной базе — «будет поменяно 22, уже в порядке 22, не найдено 0».

## Что делает Danil

1. Сделать бэкап и запустить `fix:evw-order` без `EVW_APPLY` на нужной базе, сверить список.
2. Запустить с `EVW_APPLY=1` (для libsql — с `NODE_ENV=production`, как у `import-evw.ts`).
3. Для новых турниров порядок брать из карты или оставить перемешивание.

## Рядом поправлено

- Голос не теряется молча при часах клиента впереди сервера (`features/voting/service.ts`), сетевая ошибка даёт понятный текст.
- `Spoiler`: `aria-label` с именами борцов у кнопки «Счёт», фокус переходит на открытый результат.
- `handStats` / `computeWinRates`: матч без названного победителя не считается поражением (тест добавлен).
- Votes: `match`, `deviceId`, `ipHash` не правятся из админки (field access). Удаление матча убирает его голоса (`beforeDelete` в Matches, проверено в `scripts/audit-db.ts`, F6).
- Запросы: рейтинг не считается при выключенном голосовании (`getDisplayedRatings`); счётчик матчей турниров и стиль борцов — одним запросом вместо N+1.
- Карточка матча кликабельна целиком, «Карта» 10 px, кнопка закрытия модалки 44×44.
- `sitemap.xml` и `robots.txt` (`src/app/sitemap.ts`, `robots.ts`); CI гоняет `audit-db` на временной SQLite.
- Зависимости: Next 16.3.6 → 16.4.2, Payload 3.90.0 → 3.91.0, sharp 0.35.5. Остались 11 high в `npm audit` (цепочка braces/micromatch/sass внутри Payload, исправления в registry нет) — следить за новыми релизами Payload.
- Карта турнира: кнопка «Я смотрел этот турнир» открывает все счета разом и помнится в localStorage зрителя
  (`EventMatches`, `Spoiler forceOpen`). Это решение зрителя, не автоматика; с сервера счёт по-прежнему не приходит в разметке,
  пока он закрыт. Расширение ограничения «счёт — по нажатию» (PROJECT.md § 12): одно нажатие на турнир вместо 15.
- Что делать с окружениями и бэкапом Turso/Blob — [env-separation.md](env-separation.md).
- `import.log` в `.gitignore`; подсказка поля `name` у борца больше не требует кириллицы.
